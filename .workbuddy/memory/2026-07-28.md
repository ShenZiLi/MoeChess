与立立完成萌象棋 v1.0 全功能首版的完整设计，产出 5 份设计文档。

### 已确认的核心设计决策

1. **版本范围**：全功能首版（玩法 + 6类皮肤 + 特效 + 6平台）
2. **美术资源**：AI 生成（ComfyUI），配合资源规格 + 导入校验管线
3. **AI 引擎**：自写 minimax + alpha-beta，3 难度（深度 2/4/6 + 评估 + 随机扰动）
4. **双人对战**：本地同屏，行动方切换时视角翻转 + 列阵音效
5. **视角方案**：2D + 程序化透视（棋盘预渲染 + 棋子按行缩放，翻转布局不翻贴图）
6. **6 类萌物皮肤**：猫、狗、仓鼠、鱼、鸟、熊猫
7. **棋子识别**：不用传统棋子字，改用**职务道具**（跨皮肤统一规则）
8. **动效节奏**：偏慢可爱（2-3秒/动作），支持 2 倍速（萌物表情头像按钮）
9. **棋局功能**：棋局记录 + 复盘（前进/后退/自动播放）
10. **适配**：基准 1080×1920 竖屏 + expand + 容器响应式布局
