# 萌象棋（MoeChess）v1.0 产品规格

- **版本**：v1.0 全功能首版
- **状态**：已确认（2026-07-28）
- **关联**：设计文档 `docs/plans/2026-07-28-moechess-design.md`、验收标准 `docs/development/acceptance-standard.md`

---

## 1. 产品定位

一款基于 Godot 4.x + GDScript 的跨平台萌系中国象棋游戏。在传统象棋玩法基础上，以**萌物皮肤 + 职务道具 + 2.5D 动态视角**为核心特色，覆盖 6 大平台。

## 2. 目标平台

Windows / macOS / Linux / Android / iOS / Web(HTML5)

## 3. 功能范围（v1.0 交付）

### 3.1 核心玩法
- 完整中国象棋规则（走法、将军、将死、和棋判定）
- 人机对战：低/中/高 三难度
- 双人对战：本地同屏，行动方切换时视角翻转 + 列阵音效

### 3.2 皮肤系统
- 第一版至少 **6 类萌物皮肤**：猫、狗、仓鼠、鱼、鸟、熊猫
- 每类皮肤含 14 棋子（7 类型 × 2 阵营）× 5 动画状态
- 棋子识别用**职务道具**（无传统棋子字），道具规则跨皮肤统一
- 皮肤专属：击杀/被击杀特效、胜利/战败动画、列阵音效、加速按钮萌物表情头像

### 3.3 视觉与动效
- 2.5D 透视棋盘（轻度倾斜、近大远小）
- 人机模式：玩家在下方，视角固定
- 双人模式：行动方切换时棋盘透视翻转 + 棋子重新布局 + 列阵音效
- 动效偏慢可爱（2-3 秒/动作），支持 2 倍速播放

### 3.4 棋局功能
- 棋局自动记录（棋谱存档）
- 复盘模式：前进/后退/自动播放，重放动画+音效

### 3.5 适配
- 基准 1080×1920 竖屏 + 响应式布局（手机竖屏/桌面横屏/平板宽屏）
- 输入抽象：鼠标（桌面/Web）+ 触屏（移动）
- 6 平台导出配置

### 3.6 辅助功能
- 图鉴页：道具→棋子对照（首次进入引导）
- 设置：皮肤选择、难度、音量、加速偏好
- 暂停/继续/重开/返回菜单
- 自动存档续局

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | AI 高难度单步 ≤ 2 秒；60fps（桌面）/ 30fps（移动/Web） |
| 正确性 | 象棋规则零错误；AI 不得送子/违规 |
| 资源 | 6 类皮肤校验脚本全通过；命名规范一致 |
| 视觉 | 正常运行不显示调试辅助层 |
| 兼容 | 6 平台均可导出运行 |

## 5. 不在 v1.0 范围内（YAGNI）

- 联机对战（架构预留，后续版本）
- 成就系统/排行榜
- 棋谱导入导出标准记谱法（内部 JSON，后续扩展）
- 多语言（先中文）
- 内购/广告

## 6. 交付物

- 可运行的 6 平台安装包/Web 版本
- 完整源码（遵循 AGENTS.md 目录规范）
- 设计文档、产品规格、验收标准、资源说明、文档索引
- 6 套完整萌物皮肤资源（AI 生成 + 校验通过）
- 单元测试 + 集成测试 + 视觉验收基准
